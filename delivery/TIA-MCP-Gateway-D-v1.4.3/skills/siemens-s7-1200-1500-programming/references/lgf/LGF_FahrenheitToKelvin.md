# LGF_FahrenheitToKelvin (FC / V3.0.1)

- **分类**：Converter operations / Temperature (§4.13.5)
- **中文功能**：华氏温度（°F）转换为热力学绝对温标开尔文（K）
- **英文简述**：This function converts a temperature value - from °Fahrenheit to °Kelvin.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value` | `Real` | `-` | Temperature to be converted in °Fahrenheit |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `Real` | Converted temperature in °Kelvin |
