# LGF_RankineToKelvin (FC / V3.0.1)

- **分类**：Converter operations / Temperature (§4.13.9)
- **中文功能**：兰氏温度（°R）转换为热力学绝对温标开尔文（K）：K = R / 1.8
- **英文简述**：This function converts a temperature value - from °Rankine to °Kelvin.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value` | `Real` | `-` | Temperature to be converted in °Rankine |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `Real` | Converted temperature in °Kelvin |
