# LGF_BinaryToGray (FC / V3.0.1)

- **分类**：Converter operations (§4.9.1)
- **中文功能**：将二进制编码格式的整数数值转换为对应的格雷码（Gray Code）
- **英文简述**：This function converts a binary coded value into a Gray-coded value.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `variableBinary utput parameter` | `DWord` | `-` | Binarycoded value to convert to Graycode |
| `Identifier` | `Data type` | `-` | Description |
| `Ret_Val` | `DWord` | `-` | Gray-coded value |
