# LGF_typeFileReadWriteDeleteTimestamp (UDT / V0.0.1)

- **分类**：Data handling (§5.4.3)
- **中文功能**：存储卡文件或执行指令操作的 DTL 单条历史时间戳记录结构体
- **英文简述**：This UDT belongs to the module `LGF_FileReadWriteDelete` and keeps a timestamp of a command or a file. If the timestamp is unknown, the default timestamp is displayed: `DTL#1970-01-01-00:00:00` .
