# LGF_SplitDWordToBits (FC / V3.0.1)

- **分类**：Converter operations / Binary types - Split and Merge (§4.11.8)
- **中文功能**：将一个 DWord 双字变量按位分解拆分为 32 个独立的布尔变量
- **英文简述**：This function splits a DWord variable into 32 Boolean / 32 Bit variables.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `doubleWord` | `DWord` | `-` | Bit sequence to be split |
