# LGF_KelvinToFahrenheit (FC / V3.0.1)

- **分类**：Converter operations / Temperature (§4.13.7)
- **中文功能**：热力学绝对温标开尔文（K）转换为华氏温度（°F）
- **英文简述**：This function converts a temperature value - from °Kelvin to °Fahrenheit.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value` | `Real` | `-` | Temperature to be converted in °Kelvin |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `Real` | Converted temperature in °Fahrenheit |
