# LGF_FahrenheitToCelsius (FC / V3.0.1)

- **分类**：Converter operations / Temperature (§4.13.4)
- **中文功能**：华氏温度（°F）转换为摄氏温度（°C）：C = (F - 32) / 1.8
- **英文简述**：This function converts a temperature value - from °Fahrenheit to °Celsius.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value` | `Real` | `-` | Temperature to be converted in °Fahrenheit |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `Real` | Converted temperature in °Celsius |
