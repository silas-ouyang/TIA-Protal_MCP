# LGF_StringToInt (FC / V3.0.1)

- **分类**：Converter operations (§4.9.19)
- **中文功能**：解析包含数字的文本字符串并将其转换为 DInt 类型有符号整数
- **英文简述**：This function converts a variable of data type `String` into a variable of data type `DInt` .

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value` | `String` | `-` | String value to be converted to Double-Integer. Example: ‘+16927’ |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `DInt` | Converted Double-Integer value |
