# LGF_typeFileReadWriteDeleteTimestamps (UDT / V0.0.1)

- **分类**：Data handling (§5.4.4)
- **中文功能**：存储卡文件读写删除模块全部操作指令与文件创建时间戳汇总结构体
- **英文简述**：This UDT belongs to the module `LGF_FileReadWriteDelete` and lists all timestamps of the commands and the file, if known. If the timestamp is unknown, the default timestamp is displayed: `DTL#1970-01-01-00:00:00` .
