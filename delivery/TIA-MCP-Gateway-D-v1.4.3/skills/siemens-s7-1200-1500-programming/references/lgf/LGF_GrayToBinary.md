# LGF_GrayToBinary (FC / V3.0.1)

- **分类**：Converter operations (§4.9.13)
- **中文功能**：将格雷码（Gray Code）编码数值还原转换回标准二进制数值
- **英文简述**：This function converts a gray coded value into a binary coded value.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `variableGray` | `DWord` | `-` | Graycoded value to convert to binaryvalue |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `DWord` | Binary value |
