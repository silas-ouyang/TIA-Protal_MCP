# LGF_CelsiusToFahrenheit (FC / V3.0.1)

- **分类**：Converter operations / Temperature (§4.13.1)
- **中文功能**：摄氏温度（°C）转换为华氏温度（°F）：F = C * 1.8 + 32
- **英文简述**：This function converts a temperature value - from °Celsius to °Fahrenheit.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value utput parameter` | `Real` | `-` | Temperature to be converted in °Celsius |
| `Identifier` | `Data type` | `-` | Description |
| `Ret_Val` | `Real` | `-` | Converted temperature in °Fahrenheit |
