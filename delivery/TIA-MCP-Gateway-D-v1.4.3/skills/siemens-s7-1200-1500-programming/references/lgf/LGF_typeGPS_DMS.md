# LGF_typeGPS_DMS (UDT / V3.0.1)

- **分类**：Date and timer operations (§5.2.4)
- **中文功能**：传统度分秒格式（GPS-DMS）单轴地理坐标数据类型
- **英文简述**：Datatype for GPS Coordinates in Degree, Minutes, Seconds and the Direction. Can be used for latitude and as well for longitude. The Datatype is used e.g. in `LGF_typeGPS` .
