# LGF_IntToString (FC / V3.0.1)

- **分类**：Converter operations (§4.9.14)
- **中文功能**：将 DInt 有符号长整型数值格式化转换为 ASCII 文本字符串
- **英文简述**：This function converts a variable of the data type `DInt` into a variable of the data type `String` .

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value` | `DInt` | `-` | Double-Integer value to convert |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `String` | Converted value as string. Example: ‘+16927’ |
