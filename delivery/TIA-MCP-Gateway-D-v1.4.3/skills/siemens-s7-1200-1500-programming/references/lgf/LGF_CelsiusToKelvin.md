# LGF_CelsiusToKelvin (FC / V3.0.1)

- **分类**：Converter operations / Temperature (§4.13.2)
- **中文功能**：摄氏温度（°C）转换为热力学开尔文温标（K）：K = C + 273.15
- **英文简述**：This function converts a temperature value - from °Celsius to °Kelvin.

## 输入参数 (Inputs)
| 参数名 | 数据类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `value` | `Real` | `-` | Temperature to be converted in °Celsius |

## 输出参数 (Outputs)
| 参数名 | 数据类型 | 描述 |
| :--- | :--- | :--- |
| `Ret_Val` | `Real` | Converted temperature in °Kelvin |
